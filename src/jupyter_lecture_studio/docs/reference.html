Python API reference¶

jupyter_lecture_studio and lecture_studio expose the same objects. Component methods display in Jupyter by default; pass show=False to receive HTML in scripts.

LectureDeck¶

class lecture_studio.LectureDeck(course=None, *, series=None, lesson='', language='python', theme='gold', brand=None, locale=None, markup='markdown', **theme_options)¶

A course brand, a visual theme, a locale and the lecture’s components.

Component methods display immediately in Jupyter; show=False returns standalone HTML instead (use it in scripts). Re-running a notebook cell replaces what that cell added. export() saves every component.

export(path, *, title=None, include_answers=True, present=False, notes=None, fragments=False)¶

Save a standalone HTML file with embedded styles and fonts.

include_answers=False removes activity answers, quiz keys and exercise solutions from the file (a student copy). present=True adds a slideshow mode: arrow keys, fullscreen (F) and speaker notes (S); fragments=True then reveals cards one at a time. Speaker notes are only included in presentation exports unless notes says otherwise.

Parameters:

  • path (str | Path)

  • title (str | None)

  • include_answers (bool)

  • present (bool)

  • notes (bool | None)

  • fragments (bool)

Return type:

Path

export_pdf(path, *, width=None, scale=2, mode='faithful', include_answers=True, title=None, timeout=60, audit_dir=None, browser_path=None)¶

Save the deck as a PDF using the optional pdf extra.

Faithful mode preserves screen pixels as lossless images. Vector mode keeps selectable text. Animations become a deterministic static frame. Collapsible sections are open; include_answers=False hides answers.

Parameters:

lecture_studio.export_pdf(source, destination, *, width=1328, scale=2, mode='faithful', include_answers=True, title=None, timeout=60, audit_dir=None, browser_path=None)¶

Export saved HTML/JSON/notebook content without executing notebook code.

faithful embeds lossless high-resolution screen images; text is not selectable. vector preserves selectable text and embedded fonts, with possible differences in effects rendered by Chromium’s PDF engine; lecture shadows are omitted because PDF viewers flatten them unevenly. Each slide gets its own fitted page. Notebook practice cells are grouped. Collapsible sections and answers are expanded by default. Set include_answers=False to hide activity answers only. Fonts are local; external network access is disabled. Browser installation is explicit. audit_dir optionally saves PNG references and dimensions.

jupyter_lecture_studio.documentation_path()¶

Return the bundled offline documentation index as an absolute Path.

A source checkout needs python tools/build_docs.py first. Published wheels and source archives already contain the generated documentation.
