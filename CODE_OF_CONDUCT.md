# Code of conduct

This project serves teachers and students from many countries, languages and backgrounds. We expect everyone who participates in issues, pull requests and discussions to:

- be respectful and patient, especially with newcomers and with people writing in a second language;
- give constructive, specific feedback about work, never about people;
- assume good intent and ask before concluding;
- keep discussions on topic and free of harassment, discrimination and personal attacks.

Maintainers may edit or remove contributions and restrict participation for behaviour that breaks these expectations. Report concerns privately to the maintainers through the contact on the PyPI project page.

This code is adapted from the principles of the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
