# Bundled fonts

Cairo and JetBrains Mono are bundled under the SIL Open Font License 1.1. The library MIT license does not replace the font licenses.

- Cairo: https://github.com/google/fonts/tree/main/ofl/cairo — license: `src/lecture_studio/assets/fonts/cairo-OFL.txt`.
- JetBrains Mono: https://github.com/google/fonts/tree/main/ofl/jetbrainsmono — license: `src/lecture_studio/assets/fonts/jetbrainsmono-OFL.txt`.
- Exact asset URLs, sizes and SHA-256 hashes: `src/lecture_studio/assets/fonts/manifest.json`.

Font files are embedded unchanged in exported CSS as data URLs.

## Bundled documentation

Generated documentation includes Sphinx static assets (BSD-2-Clause), Furo theme assets (MIT), and Gumshoe scrollspy (MIT). Full notices are distributed under `jupyter_lecture_studio/docs/_static/licenses/`. The Furo script's existing `furo.js.LICENSE.txt` notice is preserved. Documentation fonts use the same OFL files listed above.
