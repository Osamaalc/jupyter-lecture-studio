# مراجعة فرق التصميم قبل فصل المكتبة وبعده — 0.1.1

تاريخ المراجعة: 11 أكتوبر 2026. الهدف: استعادة هوية النسخة الأصلية مع قابلية إعادة الاستخدام والعمل دون إنترنت.

## المرجع وطريقة المقارنة

- المرجع الأصلي: `library_migration_backup/python_review_5.ipynb` و`luxury_theme.css` داخل مجلد المحاضرة. لم نعدّل المرجع.
- نسخة الفصل قبل الإصلاح محفوظة في `design-audit/after-extraction.json`. ونسخة المصدر قبل هذه المراجعة محفوظة محليًا في `revision_backup/design-parity-0.1.0`؛ النسخ الاحتياطية لا تدخل حزمة التوزيع.
- شملت المقارنة غلافًا و11 شريحة و31 بطاقة و11 رسمًا و10 أنشطة. راجعنا أيضًا المحاضرة كاملة داخل Jupyter.
- عرضنا الحالات الثلاث داخل إطارات متساوية، مع نفس خلفية الصفحة وإيقاف الحركة **في صفحات المقارنة فقط** لتثبيت القياسات. بقيت الحركة فعالة في المكتبة والمحاضرة.
- قياسات عامة لـ186 عنصرًا، ثم مقارنة أوسع لـ621 سجل عنصر حسب أصناف CSS، تشمل خصائص الخط والألوان والخلفيات والتدرجات والحدود والظلال والتباعد والمحاذاة والتخطيط، وزخارف `::before` و`::after`.
- عرضا الاختبار المعلنان: 926 و390 بكسل. القيم الهندسية الفعلية في المتصفح تقارب 926.09 و389.86 بسبب مقياس العرض؛ النسخ الثلاث لها العرض نفسه في كل تجربة.
- ملفات HTML للمقارنة تضمّن الخطوط المحلية نفسها لتظل المقارنة عادلة دون اتصال. ملفات JSON الأصلية تحفظ HTML السابق كما كان، بما فيه خيارات تحميل الخطوط.

## التحسينات المقصودة التي أبقيناها

1. الخط الأصلي يعمل محليًا حتى دون اتصال؛ المصدر السابق كان يحتاج تحميل Google Fonts أو وجود الخط في المتصفح.
2. رؤوس الغلاف والشرائح والتذييل تسمح بالتفاف النص الطويل. في تجربة عرض 390 زاد الارتفاع الكلي نحو 4.29 بكسل مقارنة بالأصل بسبب التفاف الشريط العلوي؛ فجوة الشريط في العرض الضيق 8px بدل 16px، مع بقاء هندسة البطاقات والخطوط والألوان المقاسة نفسها. لم يوجد تجاوز أفقي للصفحة: `clientWidth=scrollWidth=390`.
3. اتجاه أسهم رحلة التعلم أصبح `←` ليناسب مسار العقد من اليمين لليسار. باقي الرسوم ومحتواها محفوظة.
4. المكونات الجديدة والمواد الأخرى تحتفظ باختيار الثيم والاتجاه واللغة والألوان، مع بقاء الثيم الذهبي الافتراضي مطابقًا لهوية الأصل.

هذه مقارنة تصميم دقيقة ضمن المتصفح المحلي، وليست وعدًا بتطابق كل بكسل في جميع أنظمة التشغيل. تنعيم الخطوط قد يختلف بين المتصفحات، كما تتغير الهوامش استجابةً لحجم منطقة إخراج Jupyter.

## التحقق الوظيفي

- نجاح 16 اختبارًا للمكتبة، بما فيها منع السبب الفارغ وتضمين الخطوط والمحافظة على اختيار اللون الأصلي.
- إعادة تنفيذ115 خلية للمحاضرة دون أخطاء، مع تحقق الدرجات والقيم الحدية والمشروع والملفات.
- إعادة تنفيذ دفاتر الأمثلة الثلاثة دون أخطاء، وتحديث صفحات HTML الثلاث.
- بناء wheel 0.1.1 وتثبيته في بيئة نظيفة دون IPython أو Pygments؛ عمل التصدير وتضمنت الحزمة ملفات الخط التسعة.
- نجاح قراءة مصادر Python بقواعد صياغة Python 3.10.
- معاينة المحاضرة المصححة داخل Jupyter: Cairo حاضر، ملفات WOFF2 مضمنة، ولا استيراد للخط الشبكي في الناتج.
- تجربة فتح الإجابة وإغلاقها، وإغلاق المشهد ثم فتحه؛ تعمل حركة `ls-premium-reveal` بمدة 0.8 ثانية. هذه مدة تقنية للحركة وليست وقتًا تعليميًا معروضًا للطالب.
