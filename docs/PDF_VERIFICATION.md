- المحاضرة الأصلية كاملة: 48 صفحة، من الغلاف حتى الواجب، مع الشرح والأمثلة والنتائج المحفوظة.

## حدود القياس

التطابق المثبت يخص الإطار الثابت للمحاضرة المحفوظة، بهذا العرض والدقة. لا يشمل عناصر واجهة Jupyter مثل شريط الأدوات أو حركة الانميشن، ولا يمثل ضمانًا لجميع قارئات PDF أو الطابعات أو محتوى عشوائي. الوضع الافتراضي صور عالية الدقة؛ النص غير قابل للتحديد. وضع vector يتيح النسخ والبحث وموارد الخطوط الأصلية، وقد تختلف فيه بعض تأثيرات تركيب الرسومات.

الصفحات تناسب ارتفاع المحتوى، وليست A4 ثابتة. تبقى الانميشن في المصدر؛ PDF يعرض الحالة الثابتة. جميع الأقسام والحلول تظهر مفتوحة افتراضيًا. يعمل التصدير دون اتصال، ويقرأ النتائج المحفوظة دون تنفيذ الدفتر.

## تجربة النسخة المحلية الآن

الحزمة التجريبية: `dist/pdf-preview-0.3.0.dev0/jupyter_lecture_studio-0.3.0.dev0-py3-none-any.whl`. لا تثبت 0.2.0 من PyPI للحصول على PDF؛ الميزة ما تزال محلية.

من مجلد المشروع، ثبّتها في بيئة الدفتر نفسها:

```bash
python -m pip install "dist/pdf-preview-0.3.0.dev0/jupyter_lecture_studio-0.3.0.dev0-py3-none-any.whl[pdf]"
python -m playwright install chromium --no-shell
```

أعد تشغيل Kernel إذا كان يحمل النسخة القديمة، ثم:

```python
from jupyter_lecture_studio import export_pdf
export_pdf("python_review_5.ipynb", "أساسيات بايثون - المحاضرتان.pdf")
```

لحفظ شرائح كائن معيّن فقط: `deck.export_pdf("lecture.pdf")`. بيئة اختبار جاهزة موجودة محليًا في `/tmp/jupyter-lecture-studio-pdf-dev`، وإصدارها المثبت 0.3.0.dev0.

نجحت أيضًا حزم wheel وsdist وTwine والفحص ضد تسريب المسارات المحلية والاعتمادات السرية. التثبيت الأساسي بلا إضافات لا يجلب Playwright أو مكتبات PDF؛ إضافة pdf اختيارية. جُربت ثيمات gold وocean وemerald، وعرض 768px و1328px، مع أمثلة بايثون وقواعد البيانات.

الحزمة النهائية مثبّتة ومختبرة بالمحرك الافتراضي Chromium 153.0.8010.12 دون مسار متصفح مخصص. نجح أمر إعداد PDF وأمر CLI من wheel المثبّتة.

## إصلاح الأقسام المطوية

أصبح PDF يفتح جميع عناصر details قبل قياس الصفحات، بما فيها أهداف التعلم وطريقة تشغيل الدفتر، والأقسام المتداخلة، وإجابات الأنشطة. المحاضرة المصححة 48 صفحة. فحصنا 25 قسمًا قابلًا للطي: 25 مفتوحة، ولا قسم مغلق. خيار include_answers=False أو --hide-answers يخفي حلول الأنشطة فقط إذا طلبه المحاضر. نجح اختبار محتوى أهداف التعلم وتعليمات الدفتر المتداخلة داخل PDF القابل للبحث، واختبار إعداد CLI الافتراضي.
